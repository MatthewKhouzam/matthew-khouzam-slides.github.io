# Cache Me If You Can: Diagnosing Cache Allocation Issues with Eclipse Trace Compass

## Overview
This presentation addresses the challenges of diagnosing cache allocation issues in software performance using Eclipse Trace Compass. It emphasizes the gap between high-level KPIs and actual user experiences, showcasing how tracing can reveal hidden performance problems.

## Key Topics
- **Problem Statement**: Understanding the impact of cache size on performance and why KPIs may not reflect user experience.
- **Tools**: Introduction to Trace Compass and Trace Event Logger for effective tracing and analysis.
- **Tracing Semantics**: Importance of defining what to trace and the implications of data placement and granularity.
- **Visualization**: Utilizing flame charts and graphs to visualize performance data and identify bottlenecks.
- **Takeaways**: Insights on the misleading nature of high-level KPIs and the value of tracing in uncovering performance issues.

## Conclusion
The presentation aims to foster discussions around performance metrics and the importance of tracing in achieving a true understanding of application performance.
